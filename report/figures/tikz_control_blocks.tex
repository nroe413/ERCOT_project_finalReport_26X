% GGOV1 governor and turbine path of the machine model, drawn in the same
% block-diagram grammar as tikz_gfm_controls.tex (summing junctions with
% signs, limiter glyphs with their limits, transfer-function blocks).
% Structure after the GGOV1 block diagram (PowerWorld GGOV1 description;
% IEEE PES-TR1) with the Table 1 settings: Rselect = 1 (electrical-power
% droop feedback through T_pelec), Flag = 1 (fuel flow scaled by speed),
% Kimw = 0 (power controller off), Teng = 0 (no engine delay drawn).
